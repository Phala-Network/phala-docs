Phala Private AI serves OpenAI-compatible inference at `https://inference.phala.com/v1` through an Attested Confidential Inference (ACI) gateway. The gateway runs inside an Intel TDX trusted execution environment (TEE), verifies upstream providers before forwarding, and signs a receipt for each completed response.

The [live catalog](/phala-cloud/confidential-ai/confidential-model/api-reference/models) lists available models, pricing, and capabilities. This endpoint requires TEE-capable models and attested serving for every request. See [Endpoint policy](/phala-cloud/confidential-ai/confidential-model/endpoint-policy) for routing and refusal behavior.

Attestation identifies the measured workload and its keys. A receipt binds one exchange to that keyset. Provider sessions describe the upstream evidence boundary, which varies between model CVMs, routers, and brokers. Read [Trust Boundary](/phala-cloud/confidential-ai/confidential-model/trust-boundary) before deciding which claims meet your policy.

To run your own workload on dedicated hardware, use [GPU CVM](/phala-cloud/confidential-ai/confidential-gpu/deploy-and-verify) in the Phala Cloud section. [GPU benchmarks](/phala-cloud/confidential-ai/benchmark) and [GPU CVM FAQs](/phala-cloud/confidential-ai/confidential-gpu/faqs) cover that deployment path.
