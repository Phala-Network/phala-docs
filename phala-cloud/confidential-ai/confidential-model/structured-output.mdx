## Structured Output in Private AI

Private AI supports structured output, enabling you to receive responses in specific formats such as JSON structures. This is particularly useful for applications that require data to be processed or integrated into other systems.

### Example of Structured Output

Set `PHALA_AI_API_KEY` in your environment before running the examples.

```python
import os
import requests

response = requests.post(
    "https://inference.phala.com/v1/chat/completions",
    headers={
        "Authorization": f"Bearer {os.environ['PHALA_AI_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "z-ai/glm-5.3",
        "messages": [
            {"role": "user", "content": "What is the weather like in Los Angeles?"},
        ],
        "response_format": {
            "type": "json_schema",
            "json_schema": {
                "name": "weather",
                "strict": True,
                "schema": {
                    "type": "object",
                    "properties": {
                        "location": {
                            "type": "string",
                            "description": "City or location name",
                        },
                        "temperature": {
                            "type": "number",
                            "description": "Temperature in Celsius",
                        },
                        "conditions": {
                            "type": "string",
                            "description": "Weather conditions description",
                        },
                    },
                    "required": ["location", "temperature", "conditions"],
                    "additionalProperties": False,
                },
            },
        },
    },
)

data = response.json()
info = data["choices"][0]["message"]["content"]
print(info)
```

### Find Compatible Models

```bash
curl -s https://inference.phala.com/v1/models \
  | jq -r '.data[] | select((.supported_features // []) | index("structured_outputs")) | .id'
```

## Pydantic models

```python
import os
from openai import OpenAI
from pydantic import BaseModel

client = OpenAI(
    api_key=os.environ["PHALA_AI_API_KEY"],
    base_url="https://inference.phala.com/v1"
)

class CalendarEvent(BaseModel):
    name: str
    date: str
    participants: list[str]

response = client.chat.completions.parse(
    model="z-ai/glm-5.3",
    messages=[
        {"role": "system", "content": "Extract calendar events from text"},
        {"role": "user", "content": "Team meeting tomorrow at 2pm with Alice and Bob"}
    ],
    response_format=CalendarEvent
)

event = response.choices[0].message.parsed
if event is not None:
    print(event.name)
    print(event.participants)
else:
    print(response.choices[0].message.refusal)
```
