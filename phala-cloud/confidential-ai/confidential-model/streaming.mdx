## Streaming in Private AI API

Private AI API supports streaming, enabling you to receive responses in a streaming fashion. This is particularly useful for applications that require real-time data processing or integration with other systems.

### Example of Streaming

Set `PHALA_AI_API_KEY` in your environment before running the examples.

<CodeGroup>
```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PHALA_AI_API_KEY"],
    base_url="https://inference.phala.com/v1",
)

stream = client.chat.completions.create(
    model="z-ai/glm-5.3",
    messages=[
        {
            "role": "user",
            "content": "say `Hello` 2 times fast, no other output",
        },
    ],
    stream=True,
)
for chunk in stream:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="")
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PHALA_AI_API_KEY,
  baseURL: "https://inference.phala.com/v1",
});

const stream = await client.chat.completions.create({
  model: "z-ai/glm-5.3",
  messages: [
    { role: "user", content: "say `Hello` 2 times fast, no other output" },
  ],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || "");
}
```
</CodeGroup>

### Supported Models

Check the selected model’s capabilities in [List Models](/phala-cloud/confidential-ai/confidential-model/api-reference/models). Decision models use `/v1/systemone` and do not stream.

## Raw SSE

```bash
curl --no-buffer https://inference.phala.com/v1/chat/completions \
  -H "Authorization: Bearer $PHALA_AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"z-ai/glm-5.3","messages":[{"role":"user","content":"Say hello"}],"stream":true}'
```

The response body contains SSE frames, for example:

```text
data: {"id":"chatcmpl-123","choices":[{"delta":{"content":"Hello"}}]}

data: {"id":"chatcmpl-123","choices":[{"delta":{"content":" world"}}]}

data: [DONE]
```

For receipt verification, preserve the exact SSE body bytes and wait until the stream completes. See [Streaming receipts](/phala-cloud/confidential-ai/confidential-model/receipts-and-sessions#streaming).
