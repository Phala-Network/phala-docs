The Phala endpoint is TEE-only: upstream verification is required even when the `provider` block is omitted. No request option disables this policy. This host always filters the catalog to TEE-capable models, even with `tee=false` or `tee=1`; omit the query to get the same catalog. The separate `zdr` filter accepts only `true`.
