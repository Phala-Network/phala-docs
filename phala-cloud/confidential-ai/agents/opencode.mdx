OpenCode speaks Chat Completions. Private AI Proxy configures it automatically.

## With Private AI Proxy

1. Install [Private AI Proxy](/phala-cloud/confidential-ai/agents/private-ai-proxy), choose a **Phala** profile (the default is RedPill), sign in, and turn on **Protected**.
2. On the **Agents** screen, connect **OpenCode**.
3. Restart OpenCode.

The app writes the provider into `~/.config/opencode/opencode.json` with an agent-scoped token for its local API, and
restores the file when you disconnect or stop Protected.

From the CLI, the same connection is:

```bash
pap agents connect opencode
```

## Without the Proxy

Create a key under **Private AI → API Keys** in the [Phala dashboard](https://cloud.phala.com/dashboard).

Export your Phala API key, then add a custom provider to `opencode.json` in your project:

```bash
export PHALA_AI_API_KEY="YOUR_PHALA_API_KEY"
```

```json opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "phala": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Phala",
      "options": {
        "baseURL": "https://inference.phala.com/v1",
        "apiKey": "{env:PHALA_AI_API_KEY}"
      },
      "models": {
        "z-ai/glm-5.3": {
          "name": "GLM 5.3",
          "limit": { "context": 1048576, "output": 1048576 }
        }
      }
    }
  }
}
```

Start OpenCode, run `/models`, and select the Phala model. The key is read from the process
environment. For another model, use its ID and limits from the [model catalog](/phala-cloud/confidential-ai/confidential-model/api-reference/models).

This path does not verify attestation locally; use [Private AI Proxy](/phala-cloud/confidential-ai/agents/private-ai-proxy) or the [TypeScript ACI Verifier](/phala-cloud/confidential-ai/verify/typescript-sdk). Every model on this endpoint runs in a TEE.

## Check the Connection

Run `/models` and confirm a `phala/` model is selected, then run one bounded tool task.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| OpenCode ignores the Proxy | Confirm **Connected** in the app and that Protected is on, then restart OpenCode. |
| Phala is absent from `/models` | Confirm `provider.phala` and its `models` entry are in the project's `opencode.json`. |
| No models appear | Run `opencode models phala` and read the provider error. |
