## getCurrentUser

`GET /auth/me`

Returns the authenticated user's profile, workspace, and the workspace's Balance.

**Parameters:** None

**Returns:** `CurrentUser`

| Field | Type | Description |
|-------|------|-------------|
| `user` | `object` | User info (username, email, avatar) |
| `workspace` | `object` | Active workspace (name, slug, tier) |
| `credits` | `object` | Money in the workspace: `balance` (Balance; pays for CVMs, GPU instances, and Private AI), `granted_balance` (Gifted credits; CVMs and GPU instances only, used first), `is_post_paid` (CVM usage beyond Balance is charged to the card), `outstanding_amount` (what the workspace owes) |

**Example:**

```typescript
import { createClient } from "@phala/cloud";

const client = createClient();
const me = await client.getCurrentUser();
console.log(me.user.username, me.workspace.slug);
```

<Note>
Response shape varies by API version. The `v2026-01-21` response uses nested objects; the legacy `v2025-10-28` response uses a flat structure.
</Note>
