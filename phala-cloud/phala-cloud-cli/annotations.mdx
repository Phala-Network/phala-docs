### Command: `phala annotations`

#### Syntax

```
phala annotations [options] <args>...
```

#### Description

Show or set CVM annotations: unmeasured key/value metadata for host-side tools

#### Arguments

| Argument | Description |
| -------- | ----------- |
| `<args...>` | [cvm-id] [KEY=VALUE ...]. The CVM id is optional and falls back to phala.toml; an argument containing '=' is a pair. |

#### Options

| Option | Description |
| ------ | ----------- |
| `--unset <value>` | Remove an annotation key (repeatable) |
| `--clear` | Remove every annotation |
| `--replace` | Make the given pairs the whole set instead of merging them |

#### Global Options

| ------ | ----------- |
| `-h, --help` | Show help information for the current command |

| `--timeout SECONDS` | Request timeout in seconds (default 60) |

#### Examples

* Show annotations

```bash
phala annotations app_abc123
```

* Set annotations (CVM from phala.toml)

```bash
phala annotations memory_tier=fast pin_numa=0
```

* Remove a key

```bash
phala annotations app_abc123 --unset memory_tier
```

* Replace the whole set

```bash
phala annotations app_abc123 memory_tier=fast --replace
```

* Remove every annotation

```bash
phala annotations app_abc123 --clear
```
